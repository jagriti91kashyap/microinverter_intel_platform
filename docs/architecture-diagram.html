7. Technology Stack

Frontend

React 19 Next.js 15 TypeScript 5 Tailwind CSS 4

Recharts, react-simple-maps, Framer Motion, Radix UI, shadcn/ui, Lucide icons

Authentication

NextAuth.js 4 JWT bcryptjs

Credentials provider, role-based access (Admin/Editor/Viewer), Azure AD SSO ready

AI / ML Services

OpenAI GPT-4o Anthropic Claude text-embedding-3

Extraction, summarization, translation (10 languages), vector embeddings

Data & Storage

PostgreSQL Prisma ORM pgvector Redis

BullMQ job queue, node-cron scheduler, static TypeScript data modules (current)

Crawling & Ingestion

Playwright pdf-parse SerpAPI

Headless browser crawling, hreflang regional URL discovery, PDF text extraction

Data Coverage

14 Manufacturers 81+ Products 54 Countries

91 change events (2023–2026), 70+ regional website URLs, 10 language support
